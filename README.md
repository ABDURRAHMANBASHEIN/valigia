# فاليدجا — مشروع الموقع

## كيف ترفعه لـ GitHub بدون أوامر Terminal

1. روح لـ github.com وسجّل دخول (أو أنشئ حساب لو ما عندك).
2. اضغط الزر الأخضر **New** لإنشاء repository جديد.
3. اكتب اسم زي `valigia-store`، خلّيه **Public**، ولا تضيف أي ملفات جاهزة (بدون README أو .gitignore من GitHub نفسها).
4. اضغط **Create repository**.
5. بالصفحة اللي تفتح، دوّر على رابط صغير مكتوب **uploading an existing file**.
6. اسحب **كل الملفات والمجلدات** اللي جوا هذا المجلد (`valigia-store`) وفلتها هناك — ما عدا مجلد `node_modules` أو `dist` (مو موجودين أصلاً بهالنسخة).
7. اكتب رسالة بسيطة بالأسفل زي "رفع أول نسخة" واضغط **Commit changes**.

## بعدها بـ Vercel

1. روح لـ vercel.com وسجّل دخول بحساب GitHub.
2. اضغط **Add New Project**، واختر الـ repository اللي رفعته (`valigia-store`).
3. اضغط **Deploy** بدون ما تغيّر أي إعداد — Vercel بيتعرّف على مشروع Vite تلقائياً.
4. بعد ما يخلص، بتاخذ رابط مؤقت شغال فوراً.
5. من Settings → Domains ضيف `valigia.ly` واتبع خطوات ربط الدومين اللي وضّحناها قبل.

## ملاحظة عن حفظ البيانات

الموقع يحفظ المنتجات والطلبات بمتصفحك أنت بس (localStorage) — يعني كل جهاز/متصفح يشوف نسخته الخاصة، ومسحها من إعدادات المتصفح يمسح البيانات. لو تبي البيانات تكون موحّدة لكل الزوار، لازم تربطه بقاعدة بيانات حقيقية (Supabase مثلاً) — خطوة منفصلة.
