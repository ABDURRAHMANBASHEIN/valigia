# فاليدجا — مشروع الموقع

## شو تغيّر بهذه النسخة

- **متجاوب مع الجوال بالكامل**: هيدر بقائمة منسدلة، شبكة منتجات وأقسام تتكيّف مع الشاشة الصغيرة، ولوحة التحكم عندها قائمة جانبية منزلقة بدل الشريط الثابت.
- **تسجيل دخول للزبون**: حساب (اسم + هاتف + كلمة مرور) يُخزَّن محلياً بمتصفح الزبون. **هذا نظام مصادقة تجريبي فقط، مو آمن للاستخدام الحقيقي** — لأي إطلاق فعلي لازم نظام مصادقة حقيقي من طرف خادم (Auth حقيقي).
- **إتمام طلب كامل**: عنوان (اسم، هاتف، مدينة، عنوان تفصيلي، ملاحظات) ← اختيار طريقة الدفع.
- **حوالة بنكية**: يظهر رقم الحساب (تقدر تغيّره من لوحة التحكم → الإعدادات)، ولازم الزبون يرفق سكرين شوت قبل ما يأكد الطلب.
- **الدفع عند الاستلام**: بدون أي متطلبات إضافية.
- **تسعير التوصيل يدوياً**: كل طلب جديد يدخل بحالة "بانتظار المراجعة" بدون رسوم توصيل. من لوحة التحكم → الطلبات → زر "عرض"، تقدر تشوف العنوان والسكرين شوت وتحط رسوم التوصيل بنفسك، وبعدها يتأكد الطلب.

## كيف ترفعه لـ GitHub بدون أوامر Terminal

1. روح لـ github.com وسجّل دخول (أو أنشئ حساب لو ما عندك).
2. اضغط الزر الأخضر **New** لإنشاء repository جديد.
3. اكتب اسم زي `valigia-store`، خلّيه **Public**، ولا تضيف أي ملفات جاهزة (بدون README أو .gitignore من GitHub نفسها).
4. اضغط **Create repository**.
5. بالصفحة اللي تفتح، دوّر على رابط صغير مكتوب **uploading an existing file**.
6. اسحب **كل الملفات والمجلدات** اللي جوا هذا المجلد (`valigia-store`) وفلتها هناك — ما عدا مجلد `node_modules` أو `dist` (مو موجودين أصلاً بهالنسخة).
7. اكتب رسالة بسيطة بالأسفل زي "رفع أول نسخة" واضغط **Commit changes**.

## بعدها بـ Vercel

1. روح لـ vercel.com وسجّل دخول بحساب GitHub.
2. اضغط **Add New Project**، واختر الـ repository اللي رفعته (`valigia-store`).
3. اضغط **Deploy** بدون ما تغيّر أي إعداد — Vercel بيتعرّف على مشروع Vite تلقائياً.
4. بعد ما يخلص، بتاخذ رابط مؤقت شغال فوراً.
5. من Settings → Domains ضيف `valigia.ly` واتبع خطوات ربط الدومين اللي وضّحناها قبل.

## ملاحظة عن حفظ البيانات

الموقع يحفظ المنتجات، الطلبات، الحسابات، والإعدادات بمتصفح الزائر نفسه (localStorage) — يعني كل جهاز/متصفح يشوف نسخته الخاصة، ومسحها من إعدادات المتصفح يمسح البيانات. لو تبي البيانات تكون موحّدة لكل الزوار (كل الزبائن يشوفون نفس المخزون، وأنت تشوف كل الطلبات من كل الأجهزة)، لازم تربطه بقاعدة بيانات حقيقية (Supabase مثلاً) ونظام مصادقة حقيقي — خطوة منفصلة نقدر نجهّزها لما توصلها.
